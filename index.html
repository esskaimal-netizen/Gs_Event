Camera Setup Guides:
Sony Alpha (A7 IV, A7R, A9, A1, FX3):
  1. Connect camera Wi-Fi to the same router (or PC Hotspot GrandStores-Print).
  2. Press MENU → Network → FTP Transfer Func. → set FTP Function: ON.
  3. Select Server Setting 1 → Destination Setting: Host: 192.168.1.x  |  Port: 2121  |  Directory: /
  4. Under User Info: Username: camera  |  Password: camera  |  PASV Mode: ON.
  5. Enable Auto FTP Transfer: ON. Every photo taken will transfer instantly to Studio Pro!
Canon EOS / R Series (R3, R5, R6, 1D X, 5D IV):
  1. Connect camera Wi-Fi to the PC Hotspot or Studio Wi-Fi.
  2. Press MENU → Network Settings → FTP transfer → Create with wizard.
  3. Target server: Enter Host IP 192.168.1.x  |  Port: 2121.
  4. Passive mode: Enable  |  Target folder: Root.
  5. Login: User camera  |  Password camera.
  6. Set Automatic transfer: Enable. Photos stream automatically to the monitor!
Nikon Z / D Series (Z9, Z8, Z6, Z7, D850, D6):
  1. Connect camera Wi-Fi to the network / PC Hotspot.
  2. Go to Setup Menu (Wrench) → Connect to FTP server → Create profile.
  3. Host name: 192.168.1.x  |  Port: 2121  |  PASV: ON.
  4. User ID: camera  |  Password: camera.
  5. Turn Auto send: ON. Photos appear on the 6-frame screen with zero lag.
Fujifilm X / GFX Series (X-T5, X-H2, GFX100):
  1. Connect camera to the local Wi-Fi / Hotspot.
  2. Go to SET UP → Network/USB Setting → Communication Setting → select FTP.
  3. Server address: 192.168.1.x  |  Port: 2121  |  PASV: ON.
  4. User: camera  |  Password: camera.
  5. Select Auto transfer: ON. Shutter triggers transfer straight into the software.
